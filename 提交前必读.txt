先亲自运行这三个情境
1. An ambiguous request → Dental check → Confirm cancellation → Undo last cancellation。
2. Intention missing from options → None of these → 输入 Friday → Send → 检查 A103，再确认。

一定要理解的边界
这是真实可运行的交互原型，但语言解释使用词汇规则；虚构预约和候选遗漏是模拟条件。
没有 LLM、真实预约服务或用户实验。不要在提交时称其训练了模型、降低了认知负荷或证明某策略更好。
README 如实披露 Codex 生成代码和报告，以及已进行的检查。你应亲自查看并修改，不要声称自己完成了未做过的工作。

发布时
1. 在你自己的 GitHub 账户建立空的公开仓库，例如 repairlab。
2. 使用本目录现有的 Git 历史，设置真实 origin 并推送 main；不要重新编造开发记录。
3. 检查 README 和证据文件可公开查看，再将链接和提交版本加入报告。
4. 按 Canvas 要求提交项目报告；这些源码和图件既然放在仓库，通常无需再提交 ZIP。
